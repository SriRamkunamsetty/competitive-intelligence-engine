# Competitive Intelligence Engine

## Purpose

Turns category conversation and creative signals into a documented benchmark point of view for media and entertainment teams.

## Core capabilities

- Share-of-voice, topic velocity, and format-pattern benchmarking.
- Source coverage and taxonomy versioning.
- Creative-opportunity recommendations with confidence labels.
- Explicit restrictions on inferred competitor paid-spend claims.

## Production requirements

- Use public or contractually licensed data only.
- Preserve source type, collection time, taxonomy version, and confidence state.
- Document coverage gaps; absence of observation is not evidence of absence.
- Human methodology review before presenting conclusions externally.

## Workspace API

`GET /api/v1/projects/competitive-intelligence-engine/workspace`

Returns source-governance and benchmark methodology policy.
